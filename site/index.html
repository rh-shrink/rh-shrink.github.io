How it's measured

Text search, not Lean. All numbers come from plain text search, with Python regular expressions (like grep), over the .lean files as stored in git (collect.py). Lean is never run and nothing is elaborated.

Every commit on main (first parent: one point per merged pull request). A GitHub Action checks for new commits every 15 minutes.

Files
.lean files under src/
Lines
all lines of these files
Code lines
lines without blank lines and comments (--, nested /- -/)
Theorems
lines starting with theorem or lemma, also after attributes and modifiers such as @[simp] private
Definitions
lines starting with def, abbrev, instance, structure, inductive, class, opaque or axiom, likewise
Imports
import statements (also public import, meta import), counted as lines starting with one, assuming the usual one import per line

Because this is text search, declarations generated by commands and macros are not counted, and a match inside a comment is.
